## Non-negotiable rule

Public EDITIONS must only show:
- design files already approved by Melisa, or
- future design proposals explicitly approved before publication.

Never synthesize, reinterpret, or publish a replacement design automatically.

## Future proposal workflow

1. PHOTO source stays original.
2. AI may propose 2–3 layout concepts as PREVIEWS only.
3. Melisa approves one or rejects all.
4. Only after approval, recreate the selected layout deterministically at production quality.
5. Build product/placement-specific production file using the exact supplier template.
6. Validate dimensions, DPI, safe area, transparency, sRGB and file format.
7. Mark production file APPROVED.
8. Only approved production files are downloadable / usable for Printful.

## Production files

An EDITION may have multiple production files, for example:
- Creator 2.0 / front
- Comfort Colors 1717 / front
- Blaster 2.0 / front
- sweatshirt regular / front
- sweatshirt oversized / front
- tote / front
- postcard
- print

Each production file must store:
- supplier
- product/model
- placement
- technique
- template/version
- print area dimensions
- pixel dimensions
- target DPI
- color profile
- transparency requirement
- source edition
- status: DRAFT / REVIEW / APPROVED
- downloadable master path

## Public vs private files

Public website:
- optimized source-photo previews
- optimized approved-edition previews

Private storage:
- HEIC originals
- full-resolution design masters
- Illustrator/SVG/PDF sources when used
- final production PNG/JPEG/PDF files
